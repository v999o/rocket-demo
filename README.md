# Rocket-demo (Spaceinsiders mobile)

This is an adaptation of my first game "Spaceinsiders" for Android, with some additional features.
This was my first android game project

## Improvements and features from original Spaceinsiders

- Scale rearranged
- Added campaign featuring 4 levels with 4 distinct enemy type bosses
- Improved sprites and animations quality
- Added interface elements (menu buttons, pause, resume, restart buttons)
- Added highscore saving system
